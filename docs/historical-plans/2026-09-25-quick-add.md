# Quick Add (plan, 2026-09-25)

## Ask

Change **Add an idea** on a deck's page: drop the dashed card outline and keep just the text, then under it the same "— or —" divider as under **Pick a card below**, then a **Quick Add** button. Quick Add opens a dialog with a free-text box. Submitting it analyses the text with a model on OpenRouter and opens the normal add-an-idea form with the details filled in. Any URLs are visited to fill in missing details. The model should look at the deck's existing cards to match their style and tags.

## Approach

- **Server, `src/lib/quick-add.ts`**: `findUrls` (first three, trailing punctuation stripped), `pageText` (title, meta description/OpenGraph tags, visible text, capped), `buildPrompt` (deck tags + up to 40 example cards + typed text + pages), `parseReply` (lenient JSON extraction, trimmed to `cardInput`'s limits), and `extractIdea` tying them together with a call to OpenRouter's chat completions API with `response_format: json_object`. `fetch` is a parameter so tests can hand in a stand-in.
- **Action, `quickAddCard(deckId, text)`**: `requireUser`, `getEditableDeck` (so editors can use it too), the deck's cards as examples (starter cards when it has none), then `extractIdea`. Returns a draft; never saves. `QuickAddError` carries messages meant for the person.
- **Model**: `google/gemini-2.5-flash` by default for speed and cost, overridable with `OPENROUTER_MODEL`. `OPENROUTER_API_KEY` is a secret; without it the action says Quick Add isn't set up.
- **Client**: `QuickAdd.tsx` dialog (mirrors `CardEditor`'s dialog handling). `CardEditor` gets an optional `draft` prop that seeds a new card's fields. `DeckEditor` swaps the `.empty-slot add-card` button for an outline-less `.add-slot` holding **Add an idea**, the `.empty-slot-divider`, and **Quick Add**.
- **Safety**: only http(s) links are fetched, with an 8s timeout; the worker already runs with `global_fetch_strictly_public`, which blocks private addresses.

## Tests

- `src/lib/quick-add.test.ts`: URL finding, page text extraction, prompt contents, reply parsing and trimming, unreachable pages, missing key, OpenRouter failures, model override.
- `src/lib/actions/decks.test.ts`: draft returned and nothing saved, deck cards/tags in the prompt, starter-card fallback, editor vs. no access, empty text, no key, signed out.
- `src/components/decks/DeckEditor.test.tsx`: Add an idea opens an empty form; Quick Add fills in the form and saving sends those values; the next Add an idea starts empty; errors keep the typed text; Cancel.
